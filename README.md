📖 Project Overview
SpendWise is a production-ready, full-stack expense tracking web application built as a Round 2 submission for a Full Stack Developer role. It demonstrates real-world engineering skills including secure authentication, database design, REST API development, and a polished React frontend with data visualization.
Users can register securely, log transactions (income & expenses), view analytics charts, and manage their financial profile — all in a sleek dark-themed interface.

Live Project 
 https://expense-tracker-amber-delta-54.vercel.app


✨ Features
Authentication & Security
•	User registration and login with JWT (JSON Web Tokens)
•	Passwords hashed with bcrypt (salt rounds: 12)
•	Protected routes on both frontend and backend
•	Auto token refresh with Axios interceptors

Expense Management
•	Add, edit, and delete income & expense transactions
•	13 smart categories with emoji icons
•	Search, filter by type/category, and server-side pagination
•	Notes field for extra context per transaction
Analytics Dashboard
•	6-month income vs expenses trend (Line chart)
•	Category spending breakdown (Doughnut chart)
•	Bar chart comparison by category
•	Month/year selector for historical data

User Profile
•	Update display name and currency preference
•	Set a monthly budget for tracking goals
•	INR, USD, EUR, GBP, JPY currency support

🛠️ Tech Stack

Layer	Technology	Purpose
Frontend	React 18 + Vite	UI framework & build tool
Routing	React Router v6	Client-side navigation & auth guards
Charts	Chart.js + react-chartjs-2	Line, Doughnut, Bar charts
HTTP Client	Axios	API calls with JWT interceptor
Backend	Node.js + Express.js	REST API server
Database	MongoDB + Mongoose	NoSQL document storage
Auth	JWT + bcrypt	Token auth + password hashing
Validation	express-validator	Server-side input validation
Hosting (API)	Render.com (free tier)	Backend deployment
Hosting (UI)	Vercel (free tier)	Frontend deployment
DB Cloud	MongoDB Atlas (M0 free)	Cloud database
